# OANNES — Website mockup

Static design mockup for client review, published by Miko Studios.

## Preview

https://mikostudios-dev.github.io/oannes/

## Pages

- `index.html` — homepage (same design as `oannes-home.html`)
- `oannes-collection.html` — First Wave collection
- `oannes-product.html` — Crosscurrent Hooded Long Sleeve
- `oannes-journal.html` — Journal

Images are embedded in the HTML. Fonts load from Google Fonts.

This is a visual, interactive demo. Cart, newsletter, filters and product options are simulated; no orders, payments or subscriptions are processed. Some links remain placeholders and individual article pages are not included.

## Local preview

```sh
python3 -m http.server 8000
```

Open http://localhost:8000/.

GitHub Pages publishes the root of the `main` branch.
